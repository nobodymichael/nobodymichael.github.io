# NOBODY / CARBON BENTO
Rozpakuj ZIP do katalogu głównego repozytorium nobodymichael.github.io. Nadpisz wymienione pliki, nie usuwaj pozostałych (w tym bibliotek QRGEN i EXIF). Publikacja: Settings → Pages → Deploy from a branch → main → / (root).
LEBERCUT jest nadal oddzielnym repozytorium pod /lebercut/.
PULSE: 4 s; QRGEN: 1,8 s; EXIF: 2,1 s. Bez ręcznego pomijania; systemowe ograniczenie ruchu wyłącza efekty. Animacje dekoracyjne, EXIF nie usuwa pikseli podczas startu. Dane PULSE pobierają się równolegle.
Testy: sprawdzono renderowanie i zakończenie ekranów startowych w osadzonym Chromium, szerokość 390 px, linki i okno instalacji PULSE. Nie testowano API na żywo ani publikacji.
