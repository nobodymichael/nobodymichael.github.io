## 01 / CREATE — QRGEN

A versatile code generator with an integrated printing workspace.

- QR Code, Aztec, Data Matrix, Micro QR, PDF417 and linear barcodes
- Live preview, customizable colors and PNG / SVG export
- Interactive label editor with physical dimensions, rotation and precise positioning
- Alignment guides, adaptive grid, snapping and a local print preset
- A4 Print Studio with multiple copies and cutting outlines

[Open QRGEN](https://nobodymichael.github.io/tools/qr.html)

## 02 / PROTECT — EXIF

An image metadata inspector and local privacy toolkit.

- Metadata inspection and GPS detection in supported EXIF blocks
- Lossless removal of selected metadata blocks in supported JPEG, PNG and WebP files
- Deep Clean mode with image re-encoding
- Batch processing, before / after inspection and ZIP export
- SHA-256 checksums, hexadecimal header preview and JSON reports

[Open EXIF](https://nobodymichael.github.io/tools/exif.html)

## 03 / INTELLIGENCE — PULSE

A Polish-language crypto market briefing generated from public news feeds using Gemini, with source links, archived daily reports and market snapshots. PULSE uses external data and server-side scheduled generation; it does not send visitor data to Gemini. AI summaries can be incomplete or inaccurate.

[Open PULSE](https://nobodymichael.github.io/tools/pulse.html)

## Privacy by design

Images and code content are processed in the browser. No accounts, analytics or server-side file processing. Metadata inspection is format-dependent and cannot remove private information visible in image pixels. Always review the result before sharing.

## Technology

HTML, CSS and JavaScript. Hosted on GitHub Pages. Code generation and archive creation use locally hosted libraries; third-party licenses are listed in `licenses/`.
